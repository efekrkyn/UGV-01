# STM32 firmware çalışma alanı

PH8 için [safety_core.c](safety_core.c) / [safety_core.h](safety_core.h) **host üzerinde derlenebilen referans durum makinesi** var. `BOOT→SELF_TEST→IDLE→ARMING→ARMED→DRIVING`, ön şarj adımları, E-stop önceliği, 500 ms yeniden kurma beklemesi, yeni arm/reset kenarı ve15 s ARMING timeout'u [C testinde](../../tests/safety_core_test.c) sınanır. [can_protocol.c](can_protocol.c) / [can_protocol.h](can_protocol.h) ayrıca klasik CAN komut çerçevesi oturum/sıra/tazelik çözücüsüdür; [ayrı host testi](../../tests/can_protocol_test.c) tekrarlanan lease'in zaman damgasını yenilemediğini denetler. Bu kodların hiçbir STM32 HAL GPIO/FDCAN'ına veya gerçek güvenlik kesicisine bağlantısı yoktur; karta yüklenebilir firmware ya da güvenlik doğrulaması değildir. Mimari: [software_architecture.md](../../docs/software_architecture.md); durum/fault sözleşmesi [safety_architecture.md](../../docs/safety_architecture.md); pin ön tahsisi [electrical_architecture.md](../../docs/electrical_architecture.md).

Üretilecekler: CubeMX pin/saat dosyası, startup/linker, HAL adapter ve sürücü modülleri, kalibrasyon manifesti, SWD build talimatı ve HIL fault testleri. `UgvSafetyInputs` ölçülmüş/stale denetimli sensör ve güvenlik katmanlarından gelmelidir; `UgvSafetyOutputs` yalnız **istektir**, PWR kartındaki çift NC, watchdog, K1/K2 ve analog kapıyı bypass edemez. Fiziksel kart pinleri/current-limit devresi doğrulanmadan referans çekirdek araca sürüş vermez.

Masaüstü kontrolü: `cc -std=c11 -Wall -Wextra -Werror tests/safety_core_test.c firmware/stm32/safety_core.c -o /tmp/ugv-safety-core-test && /tmp/ugv-safety-core-test` ve `cc -std=c11 -Wall -Wextra -Werror tests/can_protocol_test.c firmware/stm32/can_protocol.c -o /tmp/ugv-can-protocol-test && /tmp/ugv-can-protocol-test` (repo kökünden). Hedefte monotonic `uint32_t` milisaniye saati ve her turda bütün girişlerin tazeliği sağlanır; süre farkı karşılaştırması yalnız <2³¹ ms pencerede kullanılır. Kontrol döngüsü, IWDG/WDI gerçek sürücüsü, FDCAN adaptörü, sürücü PWM ve ölçüm kalibrasyonu hâlâ açık.

A2 (24.09.2026): [servo_control.c](servo_control.c) (eklem sınırları, rampa, 100 ms ray bekleme, önce PWM sonra ray kapatma, aşırı akım latch'i, darbe eşlemesi), [light_bar.c](light_bar.c) (mod renkleri, batarya çubuğu, ≤0,5 W tavan) ve `can_protocol.c` 0x120/0x121 + AI hız tavanı. Test: `cc -std=c11 -Wall -Wextra -Werror tests/servo_light_test.c firmware/stm32/servo_control.c firmware/stm32/light_bar.c -o /tmp/ugv-servo-light-test && /tmp/ugv-servo-light-test`.
